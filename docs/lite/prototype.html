한입 모임 LITE · 시안 v0.4

신청은 탭 한 번, 모임은 요청에서 시작

원칙은 두 가지입니다. 글자는 최소로 줄이고, 화면 깊이는 1단계(목록 → 채팅방)로 맞춥니다. 모임 정보, 응답 변경, 도착 확인은 모두 채팅방 위쪽 줄에서 처리합니다.

참석 신청 과정 비교

지금

  1. 회원가입 (이메일, 비밀번호)
  2. 로그인
  3. 대시보드에서 모임 찾기
  4. 상세 페이지 진입
  5. 참가 신청, 정원이 차면 대기열
입력 4개 · 화면 5개 이상

바뀌는 방식

  1. 공유받은 링크로 접속
  2. 처음 한 번만 이름 입력
  3. 목록에서 "신청하기" 탭, 바로 채팅방 입장
로그인 없음 · 입력 1개 · 화면 1개

참석 응답과 도착 확인 흐름

  1. 1
    링크로 들어와 이름만 입력로그인 과정이 없습니다. 서버가 기기 토큰을 발급해 브라우저에 저장하므로, 다음 접속부터는 바로 목록이 열립니다. 이미 쓰고 있는 이름은 새로 만들 수 없습니다. 기기를 바꿀 때는 설정 화면의 "내 링크"를 새 기기에서 열면 같은 사람으로 이어집니다.
  2. 2
    목록에서 "신청하기"를 누르면 바로 채팅방으로아직 응답하지 않은 모임 카드에는 "신청하기"와 "못 가요" 두 버튼만 보입니다. "신청하기"를 누르면 참석으로 기록되고 곧바로 그 모임의 채팅방이 열리며, 환영 안내 메시지가 나옵니다. 1:1 세미나와 같은 방식이라 모든 신청이 채팅방에서 이어집니다.
  3. 3
    응답 변경은 채팅방 위쪽에서채팅방 위쪽 줄의 상태 버튼을 누르면 그 자리에서 참석·미정·불참 버튼이 펼쳐집니다. 별도 상세 화면은 없습니다. 참석이나 미정이 아닌 사람에게는 메시지 대신 "신청하기" 버튼만 보입니다.
  4. 4
    당일 도착 확인도 채팅방 위쪽에서모임 당일에는 채팅방 위쪽에 도착 코드 입력 칸이 생깁니다. 운영자에게는 같은 자리에 코드와 도착 인원이 보입니다.

1:1 세미나 (상시 모임)

목록 카드와 공유 미리보기에는 가격을 표시하지 않습니다. 비용은 사용자가 직접 1:1 채팅방에 들어왔을 때 첫 안내 메시지에서만 알려 줍니다.
안내 중 접수됨 일정 확정
  1. 1
    목록 맨 위에 항상 고정날짜와 정원이 없는 상시 항목입니다. "원하는 주제로 1:1로 배워요" 정도의 소개만 보입니다.
  2. 2
    들어오면 1:1 채팅방과 안내 메시지신청자와 운영자만 보는 채팅방이 자동으로 열립니다. 안내 메시지가 비용(시간당 50,000원)을 알려 주고, 온라인과 오프라인 중 하나를 고르는 버튼을 보여 줍니다.
  3. 3
    주제와 희망 일정 입력진행 방식을 고르면 안내 메시지가 주제와 희망 일정을 묻습니다. 답을 보내면 요청이 "접수됨"으로 바뀌고 운영자에게 알림이 갑니다.
  4. 4
    운영자가 채팅으로 조율하고 확정운영자 목록 맨 위에 1:1 대화가 사람별 카드로 바로 보입니다. 대화를 열어 일정을 조율하고 "확정"을 누릅니다.

"이런 모임 열어주세요" 요청 흐름

모으는 중 개설 가능 (5명 이상) 개설됨
  1. 1
    누구나 요청 작성주제, 한 줄 설명, 원하는 시기만 적습니다. 작성자는 자동으로 첫 번째 "나도 원해요"로 집계됩니다.
  2. 2
    "나도 원해요" 5명이면 개설 가능공감 수는 쿠키 5개로 표시됩니다. 5명이 모이면 운영자에게 알림이 갑니다.
  3. 3
    운영자가 요청을 모임으로 전환"모임 열기"를 누르면 제목이 채워진 개설 화면이 열리고, 날짜와 장소만 정하면 됩니다.
  4. 4
    요청자에게 자동 안내개설과 동시에 채팅방이 생기고, 새 모임은 "요청한 모임" 표시와 함께 목록에 나타납니다.

데이터 모델 초안

기존 테이블은 건드리지 않고, 같은 프로젝트에 새 lite 앱을 만들어 아래 테이블을 새로 추가합니다. 기존 회원과 기록은 이어 가지 않고 새로 시작합니다.

모델주요 필드설명
Membername(unique), device_token, is_host로그인 정보 없이 이름과 기기 토큰만 가집니다.
Meetuptitle, starts_at, location, capacity, checkin_code, from_request일반 모임입니다.
Rsvpmember, meetup, status(going/maybe/no), checked_in_at참석 응답과 도착 기록입니다.
ChatRoomkind(meetup/seminar), meetup, seminar모임 채팅방과 1:1 채팅방을 같은 구조로 다룹니다.
ChatMessageroom, member, kind(user/system/guide), bodyguide는 1:1 세미나 안내 메시지입니다.
SeminarRequestmember, mode(online/offline), topic, status1:1 세미나 요청입니다. 안내 문구와 시간당 비용은 운영자 설정 값으로 둡니다.
MeetupRequesttitle, description, preferred_period, status, meetup"이런 모임 열어주세요" 요청입니다.
RequestVoterequest, member (unique 조합)"나도 원해요" 기록입니다.

정해야 할 것

1:1 세미나 결제 방식일정이 확정된 뒤 어떻게 비용을 받을지 정해야 합니다. 채팅으로 계좌나 라이트닝 주소를 안내하는 방법과, 기존 앱의 라이트닝 결제 링크 기능을 옮겨 오는 방법이 있습니다.제안: 첫 버전은 운영자가 채팅으로 안내
1:1 세미나 최소 시간안내 메시지에서 1시간 단위로만 받을지, 30분 단위도 받을지 정해야 합니다.제안: 1시간 단위
정원과 대기열정원이 찬 뒤 "참석"을 누르는 경우의 처리 방식입니다.제안: 정원 초과 시 "미정"으로만 응답 가능, 자리가 나면 채팅방에 안내
채팅 실시간 방식지금 서버 구성(gunicorn 동기 워커)에서는 몇 초마다 새 메시지를 확인하는 폴링 방식이 가장 단순합니다.제안: 첫 버전은 3초 폴링
